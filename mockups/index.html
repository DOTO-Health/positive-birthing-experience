3 · Hydration — a gentle clock, plus the PRD's two-number check

Your brief asked for minimal input. So the nurse's only input is one tap, "Start labour clock" (shown here already running), then the app reminds the nurse to offer sips at the facility's interval. The temperature + pulse check from the PRD sits beside it as an optional assessment prompt. Interval and thresholds are protocol settings, not built-in clinical rules; no published threshold exists yet, so the advisory board must set them.
