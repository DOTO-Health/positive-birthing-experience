This page is kept in the docs structure for consistency with Doto Health's other repositories, and
in case a future phase introduces a model-based component (for example, if Learn's search evolves
beyond simple keyword matching). If that happens:

- Any model-based clinical-facing feature would need to go through the same clinical review gate
  described in [QA_PROCESS.md](https://github.com/DOTO-Health/positive-birthing-experience/blob/main/QA_PROCESS.md)
  as any other clinical content.
- This page would then be updated with actual setup instructions (local vs. API-based model,
  recommended options, etc.), following the pattern used in the case-summarization project.

If you believe a model-based component is planned that isn't reflected here, flag it — this page
reflects the PRD as currently written, not necessarily the final scope.
